# 초등 한자 공부

대한검정회 한자급수자격검정 **8급 · 7급 · 6급 · 준5급 · 5급**을 준비하는 한자 퀴즈 앱이에요. 서버 없이 브라우저에서만 돌아가고, 학습 기록은 그 브라우저(localStorage)에만 저장돼요.

## 실행

**바로 쓰기**: https://earthdonut17.github.io/hanja-quiz/ (설치 없이 브라우저에서 열려요. 학습 기록은 그 브라우저에만 저장돼요.)

`serve.ps1`을 실행하고 `http://localhost:8792`로 열어요. (`index.html`을 바로 열어도 돼요.)

**바탕화면 바로가기**: `powershell -NoProfile -ExecutionPolicy Bypass -File tools\create-desktop-shortcut.ps1`를 실행하면 바탕화면에 "초등 한자 공부" 바로가기가 만들어져요. 서버 없이 Edge(없으면 Chrome)의 앱 창으로 `index.html`을 열고, 학습 기록은 그 브라우저에 저장돼요. 프로젝트 폴더를 옮기면 이 스크립트를 다시 실행하세요. 아이콘은 `python tools/make-icon.py`로 다시 만들 수 있어요(Pillow 필요).

## 들어 있는 것

- **급수 한자 250자**: 8급 30 · 7급 20 · 6급 20 · 준5급 30 · 5급 150 (훈음·한자어·예문·총획)
- **교재 한자 154자**: 「초등 국어 한자가 어휘력이다」 활동지 6권에 나오는 한자 중 급수 목록에 없는 글자 (훈음 문제만)
- **문제 유형 17가지 (4지선다, 쓰기 없음)**: 기출 양식에 맞춘 훈음·한자·그림·독음·뜻·한자어·문장·반의/유의·갈래·총획·사자성어 등
- **오늘의 학습**: 핵심 5유형을 문제 유형마다 따로 복습 주기를 관리하는 간격 반복으로 공부
- **급수 마스터**: 8급부터 차례로 열리고, 한 급수의 모든 한자가 핵심 유형 레벨 4 이상이 되면 "○급 마스터" 호칭과 함께 다음 급수가 열려요(끌 수도 있어요)
- **효과음**: 정답·오답·급수 마스터 소리(소리 파일 없이 브라우저에서 합성). 오른쪽 위 🔊/🔇로 끄고 켜요
- **모의고사**: 실제 시험(가형)과 같은 문항 수·유형 순서 (8·7급 25문항, 6·준5·5급 50문항)

## 파일

| 파일 | 내용 |
| --- | --- |
| `js/hanja.js`, `hanja_g6.js`, `hanja_g5a~c.js` | 급수별 배정한자와 한자어 예시 |
| `js/hanja_extra.js` | 교재 6권에서 읽은 한자 목록 |
| `js/hanja_sentences.js` | 한자어를 넣은 예문 (새로 쓴 문장) |
| `js/hanja_meta.js` | 반의자·유의자·갈래·사자성어·생활 예절·그림 등 보조 자료 |
| `js/hanja_strokes.js` | 총획 (`tools/gen-strokes.js`로 생성) |
| `js/hanja_build.js` | 위 자료를 합쳐 `HanjaApp.HANJA`를 만듦 |
| `js/quiz.js`, `js/mockexam.js` | 문제 생성기, 모의고사 구성 |
| `js/planner.js` | 오늘의 학습에 어떤 문제를 낼지 정하는 규칙 (화면과 시뮬레이터가 함께 씀) |
| `js/progression.js` | 급수 마스터 호칭과 단계별 해금 규칙 (8급 → 7급 → 6급 → 준5급 → 5급) |
| `js/sound.js` | 효과음(Web Audio로 합성, 켜기/끄기 설정은 브라우저에 저장) |
| `js/srs.js`, `js/storage.js`, `js/stats.js`, `js/main.js` | 복습 주기, 저장, 통계, 화면 |
| `tools/make-icon.py`, `tools/create-desktop-shortcut.ps1` | 앱 아이콘(`icon.ico` 등) 생성, 바탕화면 바로가기 생성 |
| `tools/simulate-progression.js` | 급수 단계별 해금으로 5급까지 걸리는 기간 시뮬레이션 (`docs/progression-simulation.md`) |

## 검증

```bash
node tests/verify-data.js   # 공식 배정한자와 대조, 한자어·예문·획수 점검
node tests/verify-quiz.js   # 모든 한자 × 모든 유형 문제를 만들어 보기 4개·정답 1개 등을 검사
node tests/verify-progression.js   # 급수 마스터·해금 규칙, 오늘의 학습이 핵심 유형만 내는지 검사
```

  출처를 밝히고, **비영리**로만 쓰고, 고쳐서 나눌 때는 같은 조건을 적용해야 해요.
  해당 부분은 `js/hanja.js`, `js/hanja_g6.js`, `js/hanja_g5a.js`~`js/hanja_g5c.js`의 한자·훈음·급수 배정이에요.
  MIT와 달리 상업적 이용이 안 되므로, 이 앱을 상업적으로 쓰려면 급수표를 직접 대조해서 다시 만들어야 해요.

### 출처

- 급수별 배정한자: 나무위키 [「한자급수자격검정/배정한자」](https://namu.wiki/w/%ED%95%9C%EC%9E%90%EA%B8%89%EC%88%98%EC%9E%90%EA%B2%A9%EA%B2%80%EC%A0%95/%EB%B0%B0%EC%A0%95%ED%95%9C%EC%9E%90) (CC BY-NC-SA 2.0 KR). 위키 자료라서 시험 전에 [대한검정회 공식 페이지](https://www.hanja.ne.kr/jupsu/jupsu07_01.asp)와 한 번 더 대조하세요.
- **기출문제는 문제 "양식"(문항 수, 유형, 순서, 4지선다)을 파악하는 데만 썼고, 문항·보기·문장을 앱에 옮기지 않았어요.** 앱의 예문, 뜻풀이, 보기, 생활 예절 문제는 모두 새로 만든 것이에요.
- 교재(「초등 국어 한자가 어휘력이다」)에서는 한자와 훈음(과 제목)만 읽었고, 교재의 낱말·문장·그림은 옮기지 않았어요.
- 기출문제와 교재 PDF는 앱이 쓰지 않아요. 저작권이 있는 자료라서 이 저장소에 올리지 않았고(`.gitignore`로 제외), 올리지 않는 것을 권해요.
- 총획은 npm 패키지 `hanzi-writer-data`의 획 개수에 우리나라 한자 사전의 세는 법(艹·辶 등)을 맞춰 만들었어요.
- 효과음은 소리 파일 없이 브라우저(Web Audio)에서 합성해요.
