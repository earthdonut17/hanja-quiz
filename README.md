# 초등 한자 공부

대한검정회 한자급수자격검정 **8급 · 7급 · 6급 · 준5급 · 5급**을 준비하는 한자 퀴즈 앱이에요. 서버 없이 브라우저에서만 돌아가고, 학습 기록은 그 브라우저(localStorage)에만 저장돼요.

## 실행

`serve.ps1`을 실행하고 `http://localhost:8792`로 열어요. (`index.html`을 바로 열어도 돼요.)

## 들어 있는 것

- **급수 한자 250자**: 8급 30 · 7급 20 · 6급 20 · 준5급 30 · 5급 150 (훈음·한자어·예문·총획)
- **교재 한자 154자**: 「초등 국어 한자가 어휘력이다」 활동지 6권에 나오는 한자 중 급수 목록에 없는 글자 (훈음 문제만)
- **문제 유형 17가지 (4지선다, 쓰기 없음)**: 기출 양식에 맞춘 훈음·한자·그림·독음·뜻·한자어·문장·반의/유의·갈래·총획·사자성어 등
- **오늘의 학습**: 문제 유형마다 따로 복습 주기를 관리하는 간격 반복
- **모의고사**: 실제 시험(가형)과 같은 문항 수·유형 순서 (8·7급 25문항, 6·준5·5급 50문항)

## 파일

| 파일 | 내용 |
| --- | --- |
| `js/hanja.js`, `hanja_g6.js`, `hanja_g5a~c.js` | 급수별 배정한자와 한자어 예시 |
| `js/hanja_extra.js` | 교재 6권에서 읽은 한자 목록 |
| `js/hanja_sentences.js` | 한자어를 넣은 예문 (새로 쓴 문장) |
| `js/hanja_meta.js` | 반의자·유의자·갈래·사자성어·생활 예절·그림 등 보조 자료 |
| `js/hanja_strokes.js` | 총획 (`tools/gen-strokes.js`로 생성) |
| `js/hanja_build.js` | 위 자료를 합쳐 `HanjaApp.HANJA`를 만듦 |
| `js/quiz.js`, `js/mockexam.js` | 문제 생성기, 모의고사 구성 |
| `js/srs.js`, `js/storage.js`, `js/stats.js`, `js/main.js` | 복습 주기, 저장, 통계, 화면 |

## 검증

```bash
node tests/verify-data.js   # 공식 배정한자와 대조, 한자어·예문·획수 점검
node tests/verify-quiz.js   # 모든 한자 × 모든 유형 문제를 만들어 보기 4개·정답 1개 등을 검사
```

## 출처와 저작권

- 급수별 배정한자: 나무위키 「한자급수자격검정/배정한자」(비공식 위키 자료예요. 시험 전에 대한검정회 공식 자료와 한 번 더 대조하세요.)
- **기출문제는 문제 "양식"(문항 수, 유형, 순서, 4지선다)을 파악하는 데만 썼고, 문항·보기·문장을 앱에 옮기지 않았어요.** 앱의 예문, 뜻풀이, 보기, 생활 예절 문제는 모두 새로 만든 것이에요.
- 교재(「초등 국어 한자가 어휘력이다」)에서는 한자와 훈음(과 제목)만 읽었고, 교재의 낱말·문장·그림은 옮기지 않았어요.
- 폴더의 `기출문제/`와 교재 PDF는 앱이 쓰지 않아요. 저작권이 있는 자료라서 저장소에 올리거나 배포하지 않는 것을 권해요.
- 총획은 npm 패키지 `hanzi-writer-data`의 획 개수에 우리나라 한자 사전의 세는 법(艹·辶 등)을 맞춰 만들었어요.
